# Learning Roadmap

## ✅ 01 - Foundations
Computer fundamentals, operating systems, networking basics, and essential IT concepts.

## 🟨 02 - Linux
Linux command line, file systems, permissions, processes, Bash, and system administration fundamentals.

## ✅ 03 - Networking
TCP/IP, OSI Model, DNS, DHCP, HTTP/HTTPS, routing, VPNs, ports, and network communication.

## ⬜ 04 - Cybersecurity Core
CIA Triad, authentication, authorization, encryption, hashing, malware, vulnerabilities, risk management, and security principles.

## ⬜ 05 - Scripting
Python and Bash scripting for automation, log analysis, and security-related tasks.

## ⬜ 06 - Blue Team
SOC fundamentals, SIEM, Windows Event Logs, Sysmon, MITRE ATT&CK, detection, and log analysis.

## ⬜ 07 - Detection Engineering
Detection rules, Sigma, YARA, IDS/IPS, and building effective security detections.

## ⬜ 08 - Incident Response
Incident handling, triage, containment, eradication, recovery, and post-incident analysis.

## ⬜ 09 - Offensive Security
Reconnaissance, enumeration, Nmap, web security basics, privilege escalation, and attacker methodologies.

## ⬜ 10 - Certifications & Learning Logs
Learning reflections, completed learning paths, certificates, and progress tracking.

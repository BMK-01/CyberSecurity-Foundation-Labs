## What I Learned (Learning Objectives)
I explored the absolute basics of Linux CLI through hands-on tasks, simple missions, and beginner-friendly explanations.
- Understand what the Linux terminal is and what it's used for.
- Feel comfortable interacting with the Linux environment.
- Navigate through the Linux filesystem with basic commands.

## What I Practiced (Hands-on labs)
On a virtual lab machine on TryHackMe, I posed as a new IT Support Engineer hired in a Cyber Operations Support Team and was given a set of simple missions by my supervisor.
- Navigating the Linux filesystem using commands like pwd and cd
- Searched for files using commands like find
- Inspected system information using commands like whoami, uname, df -h
- Read important configuration files from the /etc
- Followed clues and completed missions inside a Linux environment.
